## The Problem With Scanned PDFs

You scan a document. You save it as PDF. But:
- You can't search for words
- You can't copy text
- You can't select anything

Why? Because a scanned PDF is just a **picture of paper**. The text isn't real — it's pixels.

## What Is OCR?

OCR stands for **Optical Character Recognition**. It's software that looks at an image of text and figures out what letters are there.

Think of it as a program that reads handwriting — except it works on typed text first.

## How OCR Works

The process is:
1. **Preprocessing** — clean the image (remove noise, straighten)
2. **Segmentation** — find lines, words, letters
3. **Recognition** — match shapes to known characters
4. **Post-processing** — fix common errors using language rules

Modern OCR is very accurate — over 99% for clean, typed scans.

## When You Need OCR

Use OCR if your PDF:
- Was created by a scanner
- Has no selectable text
- Came from a fax or photocopy
- Contains images of documents

**Test:** Open the PDF and try to select text. If you can't, it's a scanned PDF.

## Tools That Handle OCR

Not all PDF tools handle scanned documents. When choosing a tool, look for:
- Explicit OCR support
- Multiple language options
- Output as PDF (searchable) or Word

Some free tools only handle text-based PDFs. For scanned ones, you need OCR.

## Best Practices for OCR

For best results:
1. **Scan at 300 DPI** minimum
2. **Straighten pages** before scanning
3. **Good lighting** — no shadows
4. **High contrast** — black text on white paper
5. **No handwriting** unless necessary

## What OCR Gets Wrong

Common OCR errors:
- `1` and `l` confusion
- `0` and `O` confusion
- `rn` read as `m`
- Small fonts misread

Always proofread OCR output before using it.

## Conclusion

Scanned PDFs are frustrating. OCR fixes them. For simple documents, a free OCR tool is enough. For complex or handwritten text, you may need specialized software.
