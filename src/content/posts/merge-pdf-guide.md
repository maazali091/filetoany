## Why Merge PDFs?

PDFs come in pieces. You need them together.

Common reasons to merge:
- **Reports** — combine monthly reports into annual
- **Contracts** — attach appendices to the main document
- **Invoices** — group client invoices for accounting
- **Portfolios** — combine work samples into one file
- **Study material** — merge lecture notes and readings

Sending 10 separate PDFs is messy. One merged PDF is professional.

## The Importance of Order

The order of files matters. A good merger lets you **drag and drop** to rearrange pages before merging.

Example: A contract should have:
1. Cover page
2. Main agreement
3. Terms and conditions
4. Signature page
5. Appendices

Wrong order = unprofessional document.

## What About Page Numbers?

Most mergers keep original page numbers. If you need continuous numbering, you'll have to:
1. Merge first
2. Add page numbers to the merged PDF
3. Save

## File Size Considerations

Merging PDFs **adds their sizes** together:
- 5 files × 2MB each = 10MB merged file

If the merged file is too large for email, compress it after merging.

## Common Problems

**Problem:** Merge fails with password-protected PDFs.
**Fix:** Remove the password first.

**Problem:** Merged file looks different from individual files.
**Fix:** Some mergers recompress images. Use a tool that preserves quality.

**Problem:** Pages are in the wrong order.
**Fix:** Always preview order before merging.

## When Not to Merge

Don't merge if:
- Files are for different recipients
- You need to edit individual sections later
- File size becomes unmanageable

In these cases, keep them separate.
